# Manual de Usuario: FilesystemModule

## 📌 Introducción
El **FilesystemModule** es el repositorio digital de HorariosWFM. Gestiona el almacenamiento de documentos, imágenes y archivos adjuntos del sistema, asegurando que el espacio en disco sea utilizado de manera eficiente mediante un sistema de cuotas.

---

## 📂 Explorador de Archivos
- **Acceso:** `Sistema > Archivos`.
- **Funcionalidades:**
    - **Navegación:** Permite explorar las carpetas virtuales del sistema.
    - **Carga de Archivos:** Sube documentos de soporte para tickets, perfiles de empleados o noticias.
    - **Descarga:** Acceso rápido a los archivos almacenados.

---

## 📊 Gestión de Cuotas (Disk Quotas)
- **Acceso:** `Administración > Sistema > Cuotas de Disco`.
- **Concepto:** Define el límite de espacio (ej: 100MB, 1GB) que un usuario o un rol específico puede ocupar en el servidor.
- **Tipos de Límite:**
    - **Por Usuario:** Ideal para agentes que suben soportes de sus permisos.
    - **Por Rol:** Define un estándar global (ej: todos los "Supervisores" tienen 500MB).

---

## ⚠️ Consejos de Almacenamiento
1. **Formatos Estándar:** Prefiere archivos PDF para documentos y JPG/PNG para imágenes para asegurar la compatibilidad.
2. **Limpieza:** Revisa periódicamente archivos antiguos o innecesarios para no exceder tu cuota de disco.
3. **Alertas:** El sistema te notificará cuando estés cerca de alcanzar el 90% de tu capacidad de almacenamiento permitida.
