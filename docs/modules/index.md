# Manuales de Usuario por Módulo

Bienvenido a la documentación oficial de usuario de **HorariosWFM**. Este directorio contiene guías detalladas para cada uno de los módulos que componen el sistema.

## 📁 Catálogo de Módulos

### 🏗️ Gestión y Estructura
- [**CoreModule**](./core-module.md): Gestión de usuarios, roles y mantenimiento del sistema.
- [**PersonnelModule**](./personnel-module.md): Administración de empleados, equipos y jerarquía organizacional.
- [**LocationModule**](./personnel-module.md#ubicaciones-geografia): Gestión de ubicaciones geográficas.

### 📈 Operaciones y Planificación
- [**OperationsModule**](./operations-module.md): Dashboard, monitoreo en tiempo real y métricas de desempeño.
- [**WfmModule**](./wfm-module.md): Gestión de horarios, actividades intradía y autogestión del agente.
- [**ConnectModule**](./connect-module.md): Integración con Cisco Finesse y reportes de telefonía.

### 🤝 Colaboración y Soporte
- [**WorkflowsModule**](./workflows-module.md): Lógica de flujos de aprobación para solicitudes.
- [**CommunicationsModule**](./communications-module.md): Noticias, encuestas, reconocimientos y comunidad.
- [**HelpdeskModule**](./helpdesk-module.md): Sistema de tickets para soporte técnico interno.

### 🔧 Utilidades de Sistema
- [**AuditModule**](./audit-module.md): Trazabilidad total de cambios y logs de auditoría.
- [**FilesystemModule**](./filesystem-module.md): Gestión de archivos y cuotas de disco.
- [**DocumentationModule**](./documentation-module.md): Base de conocimientos y manuales técnicos.
- [**SupportModule**](./support-module.md): Servicios técnicos transversales.

### 💻 Manuales Técnicos
- [**Developer Guide**](./developer-guide.md): Arquitectura DDD, estructura de módulos y convenciones de código (Monolito Modular).
