# Manual de Usuario: SupportModule

## 📌 Introducción
El **SupportModule** es un módulo técnico de soporte interno que no posee una interfaz directa para el usuario final. Su función es actuar como una capa de servicios transversales que asiste a los demás módulos del sistema.

---

## 🛠️ Funciones Técnicas
- **Helpers y Utilidades:** Contiene funciones matemáticas, de formato de fecha o manipulación de texto que son compartidas por toda la plataforma.
- **Componentes Compartidos:** Registra elementos visuales menores o plantillas base que aseguran la consistencia estética entre Personnel, Operations y WFM.
- **Validaciones Especiales:** Define reglas de validación personalizadas que se aplican en diversos formularios de la aplicación.

---

## ⚠️ Nota para el Usuario
Si eres un usuario administrativo u operativo, **no verás menús ni botones directos** pertenecientes a este módulo. Su trabajo es "invisible" pero vital para que las demás funciones del sistema operen con fluidez y sin errores.
